# Technoventive – IT Services Landing Page

A responsive, multi-section landing page for an IT services company. Built with Bootstrap 5 and custom CSS, it presents the company's services, portfolio, client testimonials, and latest blog posts in a clean, mobile-friendly layout.

## Features

- Fixed navigation bar with an offcanvas mobile menu
- Hero section with a call-to-action
- "Why Choose Us" section with feature checklist
- Tabbed carousel showcasing Web Design, App Development, and UI/UX
- Services grid with six service cards
- Portfolio grid with hover overlays
- Client logo strip and testimonials
- Blog section with article cards
- Newsletter subscription block and multi-column footer

## Tech Stack

- HTML5
- CSS3
- Bootstrap 5.3.8 (CDN)
- Bootstrap Icons / Font Awesome 6.5.1 (CDN)
- Google Fonts: DM Sans and Poppins

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/engrahmadraza/technoventive-landing-page.git
   ```
2. Open the project folder.
3. Open `index.html` in any modern browser. No build tools or installation are required.

## Customization

- Update text and contact details in `index.html`.
- Change colors, fonts, and spacing in `style.css`.
- Replace images in the `images/` folder, keeping the same file names or updating the `src` paths.
